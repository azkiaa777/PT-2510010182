Repository ini berisi latihan mandiri Praktikum Struktur Data pada pertemuan pertama menggunakan bahasa pemrograman C++.

Pada latihan ini dilakukan beberapa percobaan, yaitu memperbaiki program `rerata.cpp` dengan mengubah pembagi dari `3.0` menjadi `5.0` sehingga menghasilkan rata-rata `84`. Selain itu, dilakukan percobaan kesalahan pada `hello.cpp` dengan menghapus tanda kutip penutup untuk mengetahui pesan error dari compiler, yaitu `missing terminating " character`. Percobaan berikutnya adalah menghapus header `<iostream>` dan melihat error `'cout' is not a member of 'std'`, karena `std::cout` membutuhkan header tersebut.

Percobaan terakhir dilakukan pada `rerata_awal.cpp` dengan membandingkan proses kompilasi menggunakan `g++` tanpa warning dan menggunakan `g++ -Wall -Wextra`. Dengan penggunaan warning, compiler memberikan peringatan bahwa variabel `tugas`, `uts`, dan `uas` belum digunakan.

Melalui latihan ini dapat dipahami cara memperbaiki kesalahan program, membaca pesan error dan warning dari compiler, serta pentingnya penggunaan opsi warning saat melakukan kompilasi program C++.
